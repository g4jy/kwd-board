# KWD 수업 판 — v6

온라인 한국어 1:1 수업 한 시간을 **공책처럼 쪽으로 넘기며** 담는 판. 글·손글씨(필압)·사진·PDF 슬라이드·HTML 자료가 한 판에 있고, 랩탑·태블릿·폰이 같은 판을 본다. 수업이 끝나면 화면 캡처 없이 **기록 묶음(.kwd.zip)** 이 남고, 밤 루틴이 녹화 전사와 시각을 맞춰 AI 문서화 입력을 2만 토큰 안쪽으로 만든다.

기획안: Claude Docs "KWD 수업 판 기획안 v3 (최종)" · 작업 기록: `LOOPLOG.md` (조사 → 루프 1~7)

## v6: 무한 판

- **판 하나, 끝없이.** 페이지를 만들지 않는다. 왼쪽에 노트 카드(선생님이 쓰는 곳), 그 밖 어디에나 그리기·글상자(빈 곳 두 번 누르기)·사진·학습지·영상. 가져온 것은 지금 보는 곳 옆 빈자리에, PDF·슬라이드는 쪽마다 한 장씩 가로로.
- **오른쪽 목록**: 판 위의 것(노트·학습지·슬라이드 쪽·사진·영상…) — 누르면 그것이 화면에 꽉 차게. 아래 `33%` = 전체 보기.
- **기기마다 같은 좌표.** 글꼴(Pretendard)을 모든 기기에 같게 받고, 폰에서도 글을 다시 흘리지 않는다(‘큰 글씨’ 없앰) → 사진·글·필기가 노트북·태블릿·폰에서 같은 자리. 폰은 두 손가락으로 확대.
- **각자 보기 + 👀 여기 보세요.** 학생은 처음 한 번 선생님 화면으로 온 뒤 자유롭게 본다. 선생님이 **여기 보세요**를 누르면 학생 화면이 선생님 화면(또는 고른 것)으로 가고 위에 "선생님: 여기 보세요"가 뜬다. 학생은 **선생님 화면으로** 단추로 언제든 따라가기. ⋯ → '학생이 내 화면 따라오기'를 켜면 계속 따라옴.
- **웹 학습지 = 수업 페이지.** 학생이 직접 누르고(⋯ → 학습지 버튼 누르기 허락), 고른 것은 선생님·학생 화면이 같이 움직인다. 그 위에 펜·**T**(글상자)로 필기하면 **학습지 단계(쪽)마다 따로** 남고, 다음 단계로 넘기면 바뀐다. **💾** = 필기 넣은 학습지 한 파일(학생 폴더 `수업필기/`, 안 되면 내려받기). 기록 묶음에도 `worksheets/` 로 들어간다.
  학습지가 단계를 알려 주는 법: `kwd.step(n, 전체)`, 판이 보내는 단계로 가기: `kwd.onGoto(fn)`, 같이 움직일 값: `kwd.state(이름, 값)` / `kwd.onState(fn)`. 예: `scripts/demo-lesson.html`.
- **과제 탭**: 지난 수업 뒤 날마다(했음·늦게·바빠서 쉼) → **수업에서 짚을 것**(고칠 것·확인 기다림) → 날마다 답·손글씨·녹음·AI 초안·선생님 피드백, 하나씩 또는 모두 판에 넣기. 출처: 학생 폴더 `과제/hw_history.json`(숙제 플랫폼이 내보낸 것) 또는 KWD 숙제 앱(`teacher.history` → 없으면 `teacher.student` + `teacher.day`).
- **오늘 탭 시간 나누기**: 브리핑에 `prep.plan`(대화·과제 피드백·수업·마무리 분)이 있으면 막대로 보이고, 누르면 그 시간 타이머.

## 체험 (모든 기능)

시작 화면 아래 **체험 (모든 기능)** 또는 `#/demo`. 지어낸 학생 Mina K 의 #12 수업이 무한 판 하나에 깔린다: 노트(과제 피드백 교정·빈칸·표) │ ① 수업 페이지(7단계 인터랙티브: 애니메이션·고르기·뒤집기·끌어다 놓기·문장 만들기) │ ② 사진·유튜브 │ ③ 듣기 영상·소리 │ ④ 학생이 낸 과제. 과제 탭에는 지난 수업 뒤 6일 과제.
고르기: **선생님(노트북)** — 폴더가 연결된 시작 화면부터 · **학생 폰** · **학생 태블릿** · **선생님 태블릿** · **나란히 보기**(선생님+학생 폰, 한쪽에서 쓰면 다른 쪽에 바로).
진짜 폴더·판은 건드리지 않는다(이 탭에서만, 위의 '끝내기'). '체험 판 처음부터 다시'로 새 판. 자료는 `node scripts/make-demo.mjs <소리 폴더>` 로 다시 만든다.

## 바로 써 보기

```bash
npm install
npm run dev            # http://localhost:5173
```

1. 학생 번호를 넣고 **새 판**.
2. **글** 을 고르고 그냥 친다. `# 제목`, `1. 리스트`, `___` (빈칸).
3. 펜 세 칸 + **형광** — 한 번 누르면 그 펜, 한 번 더 누르면 설정: 펜 종류(만년필·볼펜·붓·연필), 12색 + 끌어서 고르는 색, 굵기, 형광 진하기.
   **선택**(화살표)으로 필기·사진·글상자를 골라 옮기고 Delete. **글** 도구에서 빈 곳을 두 번 누르면 그 자리에 글상자.
4. **지우개** — 한 번 더 누르면: **획 전체 / 닿은 부분만**, 크기, "이 페이지 잉크 모두 지우기". S펜 옆 버튼을 누르고 그으면 지우개.
5. **가져오기** — 사진 · PDF·슬라이드(쪽마다 한 페이지) · 웹 학습지(페이지 위 창) · 문서(.md·.txt → 새 글 페이지) · 소리·영상(페이지 위 재생기) · 유튜브 링크 · 녹음하기 · 빈 페이지. 파일을 판 위에 끌어다 놓아도 된다.
   영상·유튜브·사진의 **⤢ 크게** → 학생 화면에도 크게 뜬다(선생님이 닫으면 모두 닫힘). 학생이 폰으로 숙제를 찍어 올리는 **📷 사진** 단추는 학생에게 쓰기를 허락했을 때만.
6. 오른쪽 숫자 = 페이지. 아래 오른쪽 `− 100% +` (가운데 숫자를 누르면 폭 맞춤). 스크롤은 마지막 페이지 아래에서 멈춘다.
7. 왼쪽 위 **← 목록** 으로 나간다. 판은 자동 저장.
8. **⋯** — 학생에게 허락(글·펜·학습지·내 커서 — 눌러도 메뉴가 안 닫힘), 한 장씩 보기, 타이머, 오늘 요약, 기록 저장(폴더 정하면 60초마다 자동), 학생 링크·방 코드, 서버·선생님 열쇠, 쪽 지우기.

태블릿: 펜 = 필기, 손가락 하나 = 이동, 두 손가락 = 확대. 폰 학생은 처음부터 "큰 글씨".

## KWD 폴더 연결 (선생님 기기만, 크롬·엣지)

시작 화면의 **KWD 폴더 연결하기**로 work 폴더(C:\KWD\work 또는 구글 드라이브 00_KWD_거울\work)를 한 번 고르면:

- 오늘 수업 시간표: `intake/<오늘>/brief_data.json` (밤 루틴·아침 브리핑이 만든 것)
- 학생 목록: `Student_Lessons/<이름 (번호)>/` — 누르면 그 학생의 오늘 판
- '이 학생' 패널: 오늘(목표·복습 단어·물어볼 것·약속·숙제·지난 수업 핵심) · 수업안·자료(`수업준비/` 의 수업안·수업페이지.html 을 한 번에 판에) · 학생 정보(프로필·로드맵·상태) · 지난 수업(문서) · 단어(`.lesson_data_*.json` 에서 바로 계산)

- 과제: 학생 폴더의 `과제/`(사진·녹음·글) + **KWD 숙제 앱**에서 낸 답·손글씨 사진·녹음 (⋯ → 더 보기 → 숙제 연결: 주소와 선생님 키, 이 기기에만 저장)
- 단어: `work/board_data/<학생 폴더>.json` 이 있으면 첫 수업부터의 **단어 전부·문형 전부**와, 누르면 이어진 말(같은 챕터·같은 묶음·헷갈리는 짝·같은 수업 묶음·같은 계열). 만들기: `python night/kwd_board_export.py` (DB 읽기만, 2초 안팎). 동의어·반의어 표와 우리말샘 벡터는 DB에 아직 없다.

파일은 브라우저 안에서 읽기만 하고, 학생 기기·서버로 보내지 않는다. AI 없음.

**Claude 앱 안 브라우저**에서는 폴더·파일 고르기 창이 열리지 않는다(눌러도 아무 일 없음 → 이제 안내가 뜬다). 크롬·엣지에서 열거나, 폴더를 시작 화면에 끌어다 놓는다.

### 수업 요약 (⋯ → 수업 요약 보기)

시간·페이지·누가 얼마나 썼나 / 학생이 쓴 글 / 배운 단어가 다시 나온 것·아직 안 나온 복습 단어 / 보여 준 자료 / **교정**(글을 골라 막대의 '교정'을 누른 것만 — 지우고 다시 쓴 건 교정이 아님, 대신 사건 기록에 남음) / **빈칸**(`___` 로 만든 칸, 학생 답·○✗) / 사건 기록 수.
사건은 전부 남긴다: 글은 한 줄마다 3초 멈출 때 한 번, 손글씨는 한 획에 한 번 → 1시간에 보통 수백~수천 개(수백 KB). 기록 묶음에 다 들어가고, AI에는 밤 루틴이 줄여서 넘긴다.

## 학생 메모리 (서버, 선택)

판 위 **이 학생** 버튼 → 지난 단어·문형·과제. 첫 쪽이 비어 있으면 "오늘 짚을 것"(오늘·복습·과제 확인)을 맨 위에 넣고, 글 속 지난 단어에는 점선 힌트가 생긴다(올려 보면 "9/24 처음 · 6번 나옴 · 오늘 복습"). 메모리는 Yjs 문서에 넣지 않아 학생 기기로 가지 않는다.

```bash
python night/kwd_night.py memory --student-dir "C:/KWD/work/Student_Lessons/이름 (번호)" --out memory.json
curl -X PUT -H "authorization: Bearer $TEACHER_TOKEN" --data-binary @memory.json https://<서버>/students/<번호>/memory.json
```

## 밤 루틴

```bash
python night/kwd_night.py all --bundle lesson_<학생>_<일시>.kwd.zip --transcript transcript.json [--memory memory.json] --out out/
```

`hint`(전사기 어휘 힌트) · `sync`(OBS 파일명 시각 + 판에 친 글과 말의 "메아리"로 시계 차이 보정) · `compact`(압축 시각표) · `prompt`(AI 입력) · `memory`. 표준 라이브러리만, 키·네트워크 없음.

## 기기 여러 대

기본은 이 기기 안에만 저장(IndexedDB). 같이 보려면 서버 하나:

| 방법 | 어떻게 |
| --- | --- |
| 로컬 Node | `TEACHER_TOKEN=… npm run server` → `ws://<랩탑 IP>:1234` |
| Cloudflare (무료, 항상 켜짐) | 아래 |

```bash
cd server/cloudflare && npm install
npx wrangler login
npx wrangler secret put TEACHER_TOKEN     # 선생님 열쇠 — 채팅에 붙여 넣지 말고 여기서 직접 입력
npm run deploy                            # wss://kwd-board-sync.<계정>.workers.dev
```

판의 ⋯ → 서버·선생님 열쇠 에 주소와 열쇠를 넣는다(열쇠는 이 기기에만 저장). 학생 링크(`r=s`)·보조기기 링크(`r=a`)에는 열쇠가 들어가지 않는다. 자료 그림은 문서 밖 서버 저장소에 둬서 Cloudflare 1MB 메시지 한도에 걸리지 않는다.

```
  palette.ts   펜 색·형광·굵기 설정

tests/                            Playwright
```
